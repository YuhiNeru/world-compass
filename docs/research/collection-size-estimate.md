# 日本語向け収集件数の暫定見込み

調査日：2026-10-09。収集を停止・再起動せず、公開ページ・公開仕様・稼働中の収集API応答から保存されたページを確認した。追加の認証情報取得やAPIへの別並行アクセスは行っていない。

## 見込み

現在の検索語・カテゴリー・日本語タグ・かな文字・関連作者という収集範囲では、**重複排除後1万～3万件程度**を低確度の暫定見込みとする。比較的広い日本分類の約9,400件を規模感の参照とし、分類されていない日本語記載や関連作者の英語名作品を補完する。ただし、日本テーマの海外作品や非公開化した作品等は一致しないため、9,392件をこの収集の下限とは扱わない。1万～3万件は実測した対象総数でも、統計的な信頼区間でもない。

明示的なjp・日本語タグだけに限定すると、小規模サービスの数百～約1,000件という規模になる。一方、このアプリは日本語の名前・説明・作者名と関連作者の公開作品も対象にするため、狭いタグ集合より広い。関連作者から多数の作品が見つかれば3万件を超える可能性もある。

[検索API仕様](https://vrchat.community/reference/search-worlds)は100件までの配列とoffsetによるページ取得を説明しており、日本語ワールド全体の総件数や国籍によるフィルターを提供していない。今回確認した応答もページごとの配列で、総数フィールドはない。チル381件はAPIページで実測した数であるが、日本語全体への単純な掛け算はしない。

まだ少数の検索語しか巡回していない。カテゴリー別の新規ID率、語同士の重複、作者別作品の追加率が集まり次第、見込みを見直す。暫定見込みの上限で収集を止めない。
