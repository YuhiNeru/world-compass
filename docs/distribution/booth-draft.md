# BOOTH説明草案 — 未公開・販売準備前

World Compass（仮称）は、気分や過ごし方からVRChatワールドを探すことを目指す、Windows向けの非公式ローカル検索ツールです。VRChat Inc.とは提携・公認関係にありません。

現時点の開発版は10件の架空ワールドのみを収録し、実在するVRChatワールドの推薦はしません。通常検索、Quest/人数/必須条件の変更、お気に入り、手動訪問記録、メモ、除外の動作を確認できます。

AI機能を導入すると、条件抽出・意味検索・提案根拠の選択を利用者のPC内で処理します。検索文、ユーザー文の埋め込み、好み、履歴、メモはサーバーへ送信しません。無断テレメトリーはありません。VRChatのログイン情報やCookieを要求・保存しません。

初回のAI導入は、GitHub/Hugging Faceの公式配布元から約1.30GB（1.209GiB）のランタイムとモデルを取得するため、通信が必要です。展開・検証用の追加空き容量も必要です。WebView2未導入時はMicrosoftの追加ダウンロードが発生します。導入済みカタログとモデルはオフラインで利用できます。初回導入が完全オフラインとは案内しません。

検索はCPU優先、同時推論1件。最低RAM・推奨スペック、日本語検索品質、VRChat同時起動時の応答時間・RAM/VRAMは未確定です。現時点では性能を保証できません。実機検証の結果を販売前にこの欄へ反映します。

本番カタログの範囲、再配布許諾、更新配信元は未確定です。現在は架空JSONの手動更新に対応しています。販売・実カタログ配布は、商用利用範囲・データ権利・名称・ライセンス表示・Windows導入の確認後に判断します。価格・発売日・国内初などの表現は未設定です。
