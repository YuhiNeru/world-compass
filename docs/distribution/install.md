# 開発版の導入

インストーラーはユーザー単位のNSIS。Python/Ollama/Node/Rustは購入者PCに要求しない。WebView2は必要で、未導入時はbootstrapperが取得する。

1. `WorldCompass-Setup-0.3.3-win-x64.exe` を起動する。開発版は未署名のため、Windowsの発行元確認が製品版と異なる。
2. 起動後、架空カタログの通常検索が利用できる。
3. AIが必要なら「セットアップ」で取得容量・保存先・配布元・ライセンスを確認し、導入ボタンを押す。以後はダウンロード・検証・配置までコマンド入力不要。
4. 「設定」でローカルAIを有効にする。AIが使えない場合は通常検索に戻る。
5. ダウンロード中断後は同じ導入ボタンで再開。破損時は検証・修復を実行する。空き容量・権限・通信のエラーを解消して再実行する。
6. 実在ワールドを検索するには、セットアップでVRChatにログインして検索DBを作る。日本語の指標がある公開ワールドを優先し、1,000件の情報と意味検索用データを保存する。画像・翻訳は表示時に保存する。

保存先は `%LOCALAPPDATA%\WorldCompass\`。アンインストール後も個人データを残す。データ削除はユーザーが保存先を確認して行う。ソースからの開発方法はREADME参照。

クリーンなWindows VM上の導入・起動・アンインストール、WebView2/VCランタイムがない状態での動作は未検証。製品版の対応OSと最低スペックは未確定。
