# 公開ワールドの個人用DB（v0.4.0）

「日本語ワールドの収集を拡張」で1,000件の上限を外し、[事前調査したカテゴリーと優先順位](../research/world-discovery-categories.md)に沿って追加する。チル・睡眠・日常利用、景観・撮影、ゲーム・謎解き、交流・音楽、展示・学習、ホラー・季節等、日本語補完の順に巡回する。分類は探索の根拠で、確認済み属性ではない。総数は未知なので固定件数に対する達成率を表示しない。

検索語・タグ・作者別のページ位置はSQLiteの `collection_queries`、巡回ページは `collection_pages`、発見元は `collection_memberships` に保存する。重複を排除し、詳細説明に日本語の指標がない候補は記録して除外する。日本語タグや関連作者で見つかった作品には英語名のものも含む。作者の国籍は推定しない。ページが反復する、または次のページをAPIが拒否する場合は巡回制限として記録する。全世界の完全網羅を意味しない。

取得ページごとに意味検索データを作り、追加済みの作品は途中でも検索できる。アプリを閉じても保存した位置から次回起動時に自動再開する。「中断して保存」は自動再開も解除する。PC停止中・アプリ終了中は収集しない。`--collect-japanese` は暗号化済みログインで拡張収集を開始する。API制限時は待機し、一時的な通信障害は最大6回、間隔を延ばして再試行する。認証失効では保存済み情報を残して停止する。

以下は最初の1,000件を作る際の手順。

セットアップ画面の「ワールド検索DBを作る」からVRChatアカウントでログインする。認証アプリまたはメールの二段階認証に対応する。ログイン完了後に公開ワールド1,000件の取得と意味検索データ生成を開始する。

パスワードと認証コードは保存しない。セッションCookieをWindows DPAPIで暗号化し、`userdata/vrchat-session.bin` に保存する。WebViewへCookieやCurrentUser全体を返さない。次回は「保存済みログインでDB構築」からセッションを確認して再開する。「ログイン情報を消去」はこのアプリの保存とメモリを消去する操作で、他アプリのログインには触れない。

一覧APIは公開のみ、最大100件ずつ。v0.3.2から日本・日本語・Japan・JP・チル・睡眠・和風・桜・カフェ等を先に検索し、日本語の名称・説明・タグと作者名を指標に取得順を決める。漢字のみの表記は弱い指標で、ひらがな・カタカナや明示的な日本語タグをより優先する。作者の国籍は取得・推定しない。候補不足時はお気に入り順で補う。IDで重複排除し、既存の公開ワールドも1,000件に含める。検索一致は体験の品質を保証しない。全公開ワールドを網羅するDBではない。

詳細APIから説明、作者、タグ、定員、取得できた対応機種を保存する。非公開化や404は除外し、別候補を補う。雨音・軽さ等の未確認属性を推定で埋めない。説明に含まれるジャンル語を順位の参考に使うが、確認済み属性には変換しない。「ちるわ」はチル系の希望として扱う。

リクエスト間隔は2秒以上。429ではRetry-Afterに従って待機・再開する。401/403、通信エラー、その他APIエラーでは取得済み情報を保持して中断する。認証の回避やブラウザからのCookie取得は行わない。

キューと優先度は個人用SQLiteの `import_queue`、ページ・取得方針・進捗は `userdata/corpus-progress.json` に保存する。中断・アプリ終了後も続きから再開できる。旧版から日本語優先への変更時は一覧ページを先頭へ戻すが、保存済みワールドとキューを保持する。`--resume-db` は暗号化済みセッションを確認して自動再開する起動オプション。強制終了時は一部情報を再取得する場合があるが、IDの重複レコードは作らない。チャット、訪問、お気に入りは削除しない。

取得後にローカル埋め込みモデルで意味検索データを生成する。入力は名称・原文・タグの先頭2,400文字まで。元の説明文は保持する。取得途中は利用可能なデータで検索でき、未生成ベクトルを検索のたびにまとめて作らない。追加データは5秒間隔で画面へ反映する。

画像と日本語訳はカード表示時に取得・保存する。ワールド本体のUnityアセットは取得しない。個人用DBを再配布する権利は確認していない。

1,000件の検索DBは20〜40MB、詳細取得は40〜90分を初期見積もりとする。意味検索データ生成時間は別途PC性能と説明文の長さに依存する。API制限や障害で延びる。進捗の保存量はSQLite・WALの合計で、既存チャットや画像も含む。
